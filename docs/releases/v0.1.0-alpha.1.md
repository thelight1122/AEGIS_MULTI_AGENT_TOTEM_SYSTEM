# AEGIS Totem v0.1.0-alpha.1

Status: Draft release notes. Do not publish until Tracey explicitly authorizes the publication gate.

## Summary

AEGIS Totem is a free, local-first developer tool for append-only repository continuity and multi-agent coordination. It gives a repository a Root Totem, Folder Totems, and one lane per human, agent, model, or instance so parallel work can coordinate without a copy/paste bridge.

## Included In This Alpha

- TypeScript CLI with `init`, lane creation, lane messaging, Folder Totem creation, Folder Totem appends, `status`, and `validate`.
- Append-only write helper with lock-directory serialization for concurrent agent writes.
- MCP stdio server exposing read, append, status, and validation tools for AI coding agents.
- VS Code extension adapter for browsing Totems and lanes, sending lane messages, and appending Folder Totem updates.
- Local install QA, MCP QA, VS Code package QA, CI, release checklist, security policy, and quickstart documentation.

## Installation During Alpha

Until npm publication is explicitly approved, use the repository build:

```bash

```

